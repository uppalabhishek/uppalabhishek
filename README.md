# Abhishek Uppal

**Design technologist in the built environment** — I automate the parts of BIM delivery that
teams otherwise do by hand. Architect by training, thirteen years in AEC across India, Qatar,

Currently a BIM Telecom Designer at Amazon, where I build Revit and construction-cloud
automation for warehouse telecom infrastructure and lead design across new-build and retrofit
sites globally.

## What I actually do

- **Turn manual review into code.** Rule-driven QA/QC over BIM submissions — naming,
  parameter completeness, LOI/LOD, classification — so a model review produces a diffable
  report instead of a comment list.
- **Talk to construction-cloud platforms via API.** Autodesk Construction Cloud / BIM 360
  administration and automation: project setup, permissions, document workflows, and
  cross-project data extraction.
- **Parametric and generative placement.** Dynamo and Python for geometry-driven layout of
  equipment, containment and devices at a scale that is not viable by hand.
- **Make delivery data visible.** Compliance and programme dashboards, plus integration
  workflows that connect portfolio-level data to project deliverables.
